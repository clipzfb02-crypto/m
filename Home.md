# Home

Start here.

- `Inbox/` holds quick captures. New notes land here by default; sort them later.
- `Notes/` holds notes you want to keep.
- `Projects/` holds one note or folder per active project.
- `Daily/` holds daily notes, one per day, named `YYYY-MM-DD`.
- `Templates/` and `Attachments/` are managed by Obsidian.

This vault syncs to GitHub with the Obsidian Git plugin. See [[README]] for setup.
